# PTDXF Examples

This directory contains reference PTDXF documents.

Purpose:

- Demonstrate PTDXF document structure
- Support validator development
- Support compatibility testing
- Provide certification test samples

## Categories

### level0

Fully compliant PTDXF documents.

Expected Result:

LEVEL 0

### level1

Documents containing removable violations.

Expected Result:

LEVEL 1

### level2

Documents containing critical violations.

Expected Result:

LEVEL 2

## Usage

These files may be used for:

- Validation testing
- Reader testing
- Certification testing
- Security evaluation
