# PTDXF Examples

This directory contains official PTDXF example documents.

All examples represent valid PTDXF documents.

Expected validator result:

```text
TRUSTED
```

The purpose of these examples is:

- Demonstrate PTDXF container structure
- Support reader development
- Support converter development
- Support validator development
- Demonstrate PTDXF best practices

All examples comply with the PTDXF specification.

Documents that should fail validation are not stored here.

Validation test cases are stored separately within the PTDXF Reference Validator project.
