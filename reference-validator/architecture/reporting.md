# Reporting

Each validation run shall generate a validation result.

---

## Report Information

Required:

- Filename
- Validation Timestamp
- Security Level
- Violations Found
- Actions Performed

---

## Example

Filename:

example.ptdxf

Timestamp:

2026-11-23 15:22

Security Level:

LEVEL 1

Violations:

- Hyperlink Found

Actions:

- Hyperlink Removed
