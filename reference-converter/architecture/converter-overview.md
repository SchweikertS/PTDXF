# Converter Overview

The converter consists of four stages.

---

## Stage 1

Document Import

Examples:

- PDF
- DOCX
- PPTX

---

## Stage 2

Content Extraction

Extract:

- Text
- Images
- Page Structure

Ignore:

- Scripts
- Macros
- Unsupported Content

---

## Stage 3

Sanitization

Remove:

- Hyperlinks
- Metadata
- Embedded Files
- Active Content

---

## Stage 4

PTDXF Generation

Generate:

- manifest.json
- page definitions
- image definitions
- security definition

Output:

PTDXF
