# Sanitization Rules

# PTDXF Sanitization Process

The sanitization process removes non-compliant content before PTDXF generation.

---

## Hyperlinks

Action:

Remove target.

Keep:

Visible text only.

---

## Metadata

Remove:

- Author
- Company
- Device Information
- GPS Data
- Creation History

---

## Comments

Remove completely.

---

## Track Changes

Remove completely.

---

## Embedded Files

Remove completely.

---

## Scripts

Remove completely.

Examples:

- JavaScript
- VBA
- ActiveX

---

## Forms

Remove completely.

---

## External Resources

Remove all references.

Examples:

- External Images
- Remote Fonts
- Web Resources

---

## Active Content

Remove completely.

---

## Sanitization Principle

Only visible information shall remain.
